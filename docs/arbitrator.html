⚖️ Arbitrator Committee

Real on-chain voting on active ScoutMarket disputes
← Back to ScoutMarket
Disputes here are resolved by a fixed 10-address juror committee registered at deployment — not a single trusted arbitrator. Every "Accept" / "Deny" click below submits a real castVote() transaction from that juror's own address. Once 3 jurors accept a challenge, the buyer is refunded and the seller's stake is slashed automatically. If accept votes can no longer mathematically reach 3, it resolves for the seller instead.

This is a UI prototype of committee deliberation, not a decentralized jury — all 10 juror keys were generated and are held by one operator for this demo. A production version needs open staking + random juror selection (e.g. Kleros), not a fixed address list.
Paste a juror's private key to vote as them. Nothing here is saved, sent anywhere, or stored — it lives only in this tab's memory until you close or reload the page.
